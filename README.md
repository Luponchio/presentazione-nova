# Presentazione Nova Severi

Sito a una pagina con il programma della Lista n°2 Nova Severi, da aprire col QR all'assemblea.
Sito statico: `index.html` + `assets/`. Il sondaggio sulla ricreazione salva i voti tramite `https://sos-nova-severi.vercel.app/api/sondaggio`.
Risultati: aprire il sito con `#risultati` in fondo all'indirizzo e inserire la password admin del S.O.S.
